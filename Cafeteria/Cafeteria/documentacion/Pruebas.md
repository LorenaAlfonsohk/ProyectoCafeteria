# Pruebas

Las pruebas automáticas están en `src/test/java`.

## Decorator
Se comprueba el precio del café, el aumento de precio de los complementos y la combinación de dos complementos.

## Strategy
Se comprueba que las promociones de lunes y hora feliz descuenten el porcentaje indicado y que la opción sin promoción no cambie el valor.

## Ejecutar
Desde la carpeta del proyecto:

```bash
mvn test
```

Los valores de precios y promociones son reglas de ejemplo definidas para este proyecto académico.
